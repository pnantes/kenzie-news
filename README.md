# Kenzie News 📰

Aplicação de notícias desenvolvida com HTML, CSS e JavaScript durante minha formação em Desenvolvimento Front-End na Kenzie Academy Brasil, em 2022.

O projeto consome uma API de notícias e utiliza os dados retornados para construir dinamicamente uma página com cards contendo informações como título, imagem, categoria, resumo e fonte.

## Funcionalidades

- Consumo de API de notícias
- Listagem dinâmica de notícias
- Exibição de título, imagem, categoria, resumo e fonte
- Criação dinâmica dos elementos no DOM
- Tratamento assíncrono das requisições

## Estrutura

O projeto separa a comunicação com a API da construção da interface.

A classe `Requisicoes` é responsável por buscar os dados da API, enquanto as classes `Noticias` e `TelaInicial` são responsáveis pela representação das notícias e sua renderização na página.

Cada notícia recebida da API é transformada em uma instância da classe `Noticias` e posteriormente em um card inserido dinamicamente no DOM.
